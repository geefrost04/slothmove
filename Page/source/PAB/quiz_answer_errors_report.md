## วิธีอ่านตาราง

- **ข้อ** = ลำดับข้อในไฟล์
- **เฉลยบอก** = ตัวอักษรที่ข้อความเฉลยระบุ (`ก.` `ข.` `ค.` `ง.`)
- **ต้องแก้ answer เป็น** = 0=ก, 1=ข, 2=ค, 3=ง
