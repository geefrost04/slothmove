🏛️ นายกรัฐมนตรี + ครม.

  • ● หัวหน้าครม. กำกับดูแลราชการแผ่นดิน
  • ● ครม. รับสนอง พ.ร.บ. ระเบียบฯ
  • ● อนุมัตินโยบายสำคัญระดับชาติ
  • ● ตราพระราชกฤษฎีกา / กฎหมายลำดับรอง

📌 รัฐมนตรี + ปลัดกระทรวง

  • ● รมต. = หัวหน้ากระทรวง กำหนดนโยบาย
  • ● ปลัดฯ = รักษาความต่อเนื่องราชการ
  • ● ปลัดฯ เป็นประธาน ก.พ.ร. (ม.11)
  • ● ปลัดฯ เป็น รมต. เมื่อ รมต. ว่าง

📋 อธิบดี + ผู้ว่าฯ + นายอำเภอ

  • ● อธิบดี = ผู้บังคับบัญชากรมในกระทรวง
  • ● ผู้ว่าฯ = ปลัดฯ มหาดไทยในจังหวัด
  • ● นายอำเภอ = รักษาความสงบเรียบร้อย
  • ● ผู้ว่าฯ → ประธาน ก.ธ.จ. (ม.34)

⚙️ ก.พ.ร. — คณะกรรมการพัฒนาระบบราชการ

  • ● ประธาน = นายกฯ/รองนายกฯ
  • ● รองประธาน = ปลัดกระทรวง
  • ● เลขา = เลขาฯ สำนักนายกฯ
  • ● พัฒนาระบบ · ตีความ · ประเมินผล

🗺️ ก.ธ.จ. — คณะกรรมการธรรมาภิบาลจังหวัด

  • ● ประธาน = ผู้ว่าราชการจังหวัด
  • ● กำหนดนโยบายและแผนพัฒนาจังหวัด
  • ● ประสานส่วนกลาง + ส่วนภูมิภาค
  • ● อนุมัติโครงการพัฒนาจังหวัด

🏡 กจ. — คณะกรรมการจังหวัด

  • ● ประธาน = นายอำเภอ
  • ● กำหนดนโยบายและแผนพัฒนาอำเภอ
  • ● ประสานกลาง + ภูมิภาค + ท้องถิ่น
  • ● อนุมัติโครงการพัฒนาอำเภอ
📚

คำศัพท์สำคัญ

📌 พ.ร.บ. ระเบียบบริหารราชการแผ่นดิน พ.ศ. 2534

มีผลบังคับใช้วันถัดจากวันประกาศในราชกิจจานุเบกษา ยกเลิกประกาศคณะปฏิวัติทั้งหมด แก้ไขเพิ่มเติม 8 ฉบับ ถึง พ.ศ. 2553

📌 ส่วนราชการ 3 ส่วน

ส่วนกลาง (กรม) — ส่วนภูมิภาค (จังหวัด + อำเภอ) — ส่วนท้องถิ่น (องค์กรปกครองส่วนท้องถิ่น)

📌 การแบ่งส่วนราชการ 4 รูปแบบ

สำนักนายกฯ · กระทรวง/ทบวง · กรม · ส่วนราชการที่เรียกชื่ออย่างอื่น (ม.4 วรรค 2)

📌 เครื่องมือบริหาร 3 อย่าง

กำหนดนโยบาย — จัดทำแผนยุทธศาสตร์ — กำหนดมาตรฐานกลาง (ก.พ.ร. ฉบับที่ 5 พ.ศ. 2545)

📌 พ.ร.บ. vs พ.ร.ฎ. vs กฎกระทรวง

พ.ร.บ. = มีอัตรากำลัง / ตั้ง-ยุบจังหวัด  |  พ.ร.ฎ. = ไม่มีอัตรากำลัง / เปลี่ยนชื่อ / ยุบอำเภอ  |  กฎกระทรวง = แบ่งภายในกรม

📌 นิติบุคคล vs ไม่เป็นนิติบุคคล

จังหวัด = นิติบุคคล (ตั้ง/ยุบ → พ.ร.บ.)  |  อำเภอ = ไม่เป็นนิติบุคคล (ตั้ง/ยุบ → พ.ร.ฎ.)  |  กอง ≠ นิติบุคคล

💡 ทิปทบทวน

จำโครงสร้างจากบนลงล่าง: นายกฯ → รมต./ปลัดฯ → อธิบดี/ผู้ว่าฯ/นายอำเภอ → ก.พ.ร./ก.ธ.จ./กจ. ข้อสอบมักถามบทบาทแต่ละตำแหน่งและความสัมพันธ์ในโครงสร้าง
