แนวคิดหลัก

📌 นิติบุคคล (Juristic Person)
ฐานะที่ทำให้หน่วยงานเป็นคู่สัญญาและฟ้องร้องได้ — มีเฉพาะ สนร./กระทรวง/ทบวง/กรม เท่านั้น กอง ≠ นิติบุคคล ตั้ง/ยุบ → พ.ร.บ. ส่วนกลาง
📌 ธรรมาภิบาล (Good Governance)
หลักการบริหารกิจการบ้านเมืองที่ดี เพิ่มโดยฉบับที่ 5 (พ.ศ. 2545) กำหนดนโยบาย ผลสัมฤทธิ์ ประสิทธิภาพ ลดขั้นตอน กระจายอำนาจ อำนวยความสะดวก ธรรมาภิบาล ประเมินผล
📌 การประเมินผลการปฏิบัติราชการ
ประเมินผลการปฏิบัติราชการตามมาตรา 3/1 วรรค 8 (ฉบับที่ 5 พ.ศ. 2545) ทำให้ส่วนราชการรับผิดชอบต่อผลงาน ตรวจสอบได้ โปร่งใส
📌 ผลสัมฤทธิ์ของภารกิจของรัฐ
เป้าหมายตามมาตรา 3/1 วรรค 2 วัดจากปริมาณงาน คุณภาพ ความรวดเร็ว ความคุ้มค่า ความพึงพอใจของประชาชน
⚖️

สถานะทางกฎหมาย

📌 นิติบุคคล vs ไม่เป็นนิติบุคคล
นิติบุคคล = สนร./กระทรวง/ทบวง/กรม (ตั้ง/ยุบ → พ.ร.บ.) | ไม่เป็นนิติบุคคล = กอง/อำเภอ (ตั้ง/ยุบ → พ.ร.ฎ.) | กอง ≠ นิติบุคคล เสมอ
📌 ส่วนราชการส่วนกลาง 4 รูปแบบ
1. สำนักนายกรัฐมนตรี (เทียบเท่ากระทรวง) | 2. กระทรวง/ทบวงที่เทียบเท่า | 3. ทบวง | 4. กรม (หรือส่วนราชการที่มีฐานะเป็นกรม)
🔄

การดำเนินงาน

📌 การมอบอำนาจ (Delegation)
ใช้คำว่า 'ปฏิบัติราชการแทน' — ตัวจริงยังอยู่ แต่มอบงานให้ผู้ใต้บัญชาทำแทน ได้รับอำนาจเฉพาะที่มอบเท่านั้น เพื่อความรวดเร็ว
📌 การรักษาราชการแทน (Acting)
ใช้คำว่า 'รักษาราชการแทน' — ตัวจริงไม่อยู่หรือตำแหน่งว่าง ได้รับอำนาจเทียบเท่าผู้ดำรงตำแหน่งทุกประการ เพื่อไม่ให้งานหยุดชะงัก
📌 กลุ่มภารกิจ (Cluster)
รวมกรมตั้งแต่ 2 ส่วนราชการขึ้นไปภายในกระทรวง มีรองปลัดกระทรวงดูแล เพื่อประสิทธิภาพ ลดความซ้ำซ้อน บูรณาการภารกิจ
📌 ส่วนราชการส่วนกลาง
ส่วนราชการที่จัดตั้งโดย พ.ร.บ. มีฐานะนิติบุคคล สามารถเป็นคู่สัญญาและฟ้องร้องได้ ประกอบด้วย สนร./กระทรวง/ทบวง/กรม
📌 กอง (ไม่เป็นนิติบุคคล)
หน่วยงานภายในกรม ไม่มีฐานะนิติบุคคล ไม่สามารถเป็นคู่สัญญาเองได้ อยู่ภายใต้กรม ตั้ง/ยุบโดย กฎกระทรวง
📌 หน่วยบริการเฉพาะ (Ambassador)
หน่วยงานที่จัดตั้งตามกฎหมายเฉพาะ อาจมีฐานะเป็นนิติบุคคลหรือไม่ก็ได้ ขึ้นอยู่กับกฎหมายนั้นๆ มักเป็นหน่วยงานที่ต้องให้บริการเฉพาะทาง
👥

คณะกรรมการและคณะอนุกรรมการ

📌 ก.พ.ร. — คณะกรรมการพัฒนาระบบราชการ
ประธาน = นายกฯ/รองนายกฯ | รองประธาน = ปลัดกระทรวง | เลขา = เลขาฯ สปน. ทำหน้าที่พัฒนาระบบราชการ ตีความกฎหมาย ประเมินผล ≠ ก.พ. (ข้าราชการพลเรือน)
📌 ก.ธ.จ. — คณะกรรมการธรรมาภิบาลจังหวัด
ประธาน = ผู้ว่าราชการจังหวัด | สอดส่องหน่วยงานรัฐในจังหวัดให้ใช้หลักธรรมาภิบาล กำหนดนโยบายและแผนพัฒนาจังหวัด อนุมัติโครงการพัฒนาจังหวัด
📌 คณะกรมการจังหวัด
ที่ปรึกษาผู้ว่าราชการจังหวัด ประกอบด้วยหัวหน้าส่วนราชการในจังหวัด สนับสนุนการบริหารจังหวัด ประสานงานราชการส่วนกลางและส่วนภูมิภาค
📌 กจ. — คณะกรรมการจังหวัด (อำเภอ)
ประธาน = นายอำเภอ | กำหนดนโยบายและแผนพัฒนาอำเภอ | ประสานกลาง+ภูมิภาค+ท้องถิ่น | อนุมัติโครงการพัฒนาอำเภอ | วงเงิน 200,000 บาท
📜

รูปแบบกฎหมายจัดตั้ง/เปลี่ยนแปลงส่วนราชการ

📌 พ.ร.บ. (พระราชบัญญัติ)
ตราโดยรัฐสภา → จัดตั้ง/รวม/โอน (มีการเพิ่มอัตรากำลัง) และตั้ง/ยุบ/เปลี่ยนเขตจังหวัด มีผลบังคับใช้วันถัดจากวันประกาศในราชกิจจานุเบกษา
📌 พ.ร.ฎ. (พระราชกฤษฎีกา)
ตราโดย ครม. → รวม/โอน (ไม่เพิ่มอัตรากำลัง), เปลี่ยนชื่อ, ยุบเลิก, ตั้ง/ยุบ/เปลี่ยนเขตอำเภอ ใช้เมื่อไม่มีการเพิ่มอัตรากำลัง
📌 กฎกระทรวง
ตราโดยรัฐมนตรี → แบ่งส่วนราชการภายในกรม (ตั้งกอง/สำนักงานเลขานุการกรม) ใช้สำหรับการจัดโครงสร้างภายในเท่านั้น ไม่กระทบภายนอก
🔢
