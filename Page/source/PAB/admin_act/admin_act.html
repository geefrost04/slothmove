🏛️ นายกรัฐมนตรี + ครม.

  • หัวหน้าครม. กำกับดูแลราชการแผ่นดิน
  • ครม. รับสนอง พ.ร.บ. ระเบียบฯ
  • อนุมัตินโยบายสำคัญระดับชาติ
  • ตราพระราชกฤษฎีกา / กฎหมายลำดับรอง

📌 รัฐมนตรี + ปลัดกระทรวง

  • รมต. = หัวหน้ากระทรวง กำหนดนโยบาย
  • ปลัดฯ = รักษาความต่อเนื่องราชการ
  • ปลัดฯ เป็นประธาน ก.พ.ร. (ม.11)
  • ปลัดฯ เป็น รมต. เมื่อ รมต. ว่าง

📋 อธิบดี + ผู้ว่าฯ + นายอำเภอ

  • อธิบดี = ผู้บังคับบัญชากรมในกระทรวง
  • ผู้ว่าฯ = ปลัดฯ มหาดไทยในจังหวัด
  • นายอำเภอ = รักษาความสงบเรียบร้อย
  • ผู้ว่าฯ → ประธาน ก.ธ.จ. (ม.34)

⚙️ ก.พ.ร. — คณะกรรมการพัฒนาระบบราชการ

  • ประธาน = นายกฯ/รองนายกฯ
  • รองประธาน = ปลัดกระทรวง
  • เลขา = เลขาฯ สำนักนายกฯ
  • พัฒนาระบบ · ตีความ · ประเมินผล

🗺️ ก.ธ.จ. — คณะกรรมการธรรมาภิบาลจังหวัด

  • ประธาน = ผู้ว่าราชการจังหวัด
  • กำหนดนโยบายและแผนพัฒนาจังหวัด
  • ประสานส่วนกลาง + ส่วนภูมิภาค
  • อนุมัติโครงการพัฒนาจังหวัด

🏡 กจ. — คณะกรรมการจังหวัด

  • ประธาน = นายอำเภอ
  • กำหนดนโยบายและแผนพัฒนาอำเภอ
  • ประสานกลาง + ภูมิภาค + ท้องถิ่น
  • อนุมัติโครงการพัฒนาอำเภอ
💡 ทิปทบทวน

อ่านตามลำดับทีละหัวข้อ แล้วทดลองทำข้อสอบดู — ข้อสอบมักถามทั้งนิยาม ขั้นตอน และบทบาทของหน่วยงาน
